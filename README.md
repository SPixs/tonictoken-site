# Tonic Token — règles de confidentialité

La page publique des règles de confidentialité du jeu Android *Tonic Token*
(`org.pixs.tonictoken`), servie par GitHub Pages :
<https://spixs.github.io/tonictoken-site/>.

Sa source est `docs/confidentialite.html` du dépôt du jeu ; `index.html` en
est la copie publiée.
